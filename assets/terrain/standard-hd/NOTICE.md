# Enhanced terrain asset notice

This directory contains 601 selected enhanced terrain tiles following the original Dungeon Keeper STANDARD terrain shapes, materials and colours. Original Dungeon Keeper designs and source material retain their respective ownership.

This is a free fan mod and requires a legally owned copy of Dungeon Keeper. This project is not endorsed by or affiliated with EA or its licensors. The repository's source-code licence does not itself grant rights in original game data or change the ownership of referenced designs. Preserve this notice together with upstream licences and credits.

The published files contain enhanced 128 by 128 PNGs, their INDEX8 pixel payload and assembly metadata. Original 32 by 32 reference pixels, extracted source sheets, game captures and assembled runtime packs are excluded. Native source hashes identify the expected local files. The installer reconstructs authentication references from the user's original data; the resulting `standard-hd.kfht` contains original game pixels and must remain local.

The 24 woman and paired-figure relief cells, six solid cells and one debug cell remain native. No fallback pixels are distributed in this bundle. See the [terrain guide](../../../local-dev/terrain/README.md) for installation and validation limits.
