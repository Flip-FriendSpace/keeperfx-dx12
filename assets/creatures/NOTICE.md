# Enhanced creature sprite asset notice

This directory contains the selected enhanced PNG frames and assembly metadata for the original thirteen Dungeon Keeper heroes and the imp. The artwork follows the original characters, poses, camera headings and frame timing; original Dungeon Keeper character designs and source material retain their respective ownership.

This is a free fan mod and requires a legally owned copy of Dungeon Keeper. This project is not endorsed by or affiliated with EA or its licensors.

The repository's source-code licence does not itself grant rights in the original game data or change the ownership of referenced character designs. Preserve this notice together with existing upstream licences and credits.

Original game pixels, extracted reference images, full source sheets, rejected variants, game captures and runtime sprite ZIPs are not distributed here. The installer reads `creature.tab`, `creature.jty` and `palette.dat` from a prepared local runtime and reconstructs the unchanged original fallback views on the user's machine. Those resulting packages contain original game data and must remain local.

The selected enhanced scope is 1,688 overhead frames and 84 held frames across the thirteen heroes and imp, plus 65 enhanced native-resolution comparison frames: 1,837 published PNGs in total. Assembly recipes omit 1,669 original first-person fallback frames, which are reconstructed from local game data. Other possession views and shared effects use local original fallback art. See `local-dev/art-prototype/README.md` for installation, prerequisites and recorded review limits. This asset bundle is not a complete game or runtime distribution.
