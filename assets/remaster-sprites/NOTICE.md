# Enhanced sprite asset notice

This directory contains selected enhanced replacement artwork and assembly metadata for a free Dungeon Keeper fan mod. Original character designs and source material retain their respective ownership. A legally owned copy of Dungeon Keeper and a compatible prepared KeeperFX installation are required. This project is not endorsed by or affiliated with EA or its licensors.

The repository's source-code licence does not itself grant rights in original game data or change ownership of referenced designs. Preserve this notice together with upstream licences and credits.

Original fallback pixels, extracted references, source sheets, rejected variants, captures and runtime sprite ZIPs are not distributed here. The importer reads matching original game and upstream base-sprite data locally and reconstructs unchanged members on the player's machine. Those generated packages must remain local.

This bundle is not a complete game or runtime distribution. See README.md for scope, reconstruction requirements and verification.
